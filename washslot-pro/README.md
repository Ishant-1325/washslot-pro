# WashSlot Pro - AI-Powered Smart Hostel Laundry App

Built with Python, Flet 1.x, and SQLite.

## Included Features
- Student registration/login & Warden role login (`admin` / `admin123`)
- 4-machine live display & 7-day booking calendar
- 1-hour booking slots with daily 60-minute database restriction & conflict protection
- 15-minute pre-slot alarm banner & automatic missed-slot release (15-min grace period)
- Live 60-minute Wash / Drain / Refill / Drying cycle timer (with 60x Faculty Demo mode)
- Machine damage reporting interface & Warden live management
- Python AI Scheduling Optimizer & Demand Prediction

## How to Run
```powershell
python main.py
```
